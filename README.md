# 音乐会检索系统 (Concert Searcher)

这是一个方便快捷的现代化音乐会检索页面，支持各种条件的快速查询、过滤与曲目检索功能。

## ✨ 功能特点
- **多维度检索**：支持按“标题”或“曲目”关键词进行模糊匹配并高亮展示。
- **动态条件筛选**：全方位支持按“演出城市”、“时间区间”、“价格区间”（最低价—最高价）进行实时条件筛选。
- **自定义排序**：支持按时间（从早到晚 / 从晚到早）及价格（从低到高 / 从高到低）对结果进行全量排序。


## 📁 核心项目结构
- `index.html`: 前端主页面
- `style.css`: 页面整体响应式样式
- `script.js`: 前端交互、过滤、排序及分页的核心逻辑
- `data.js`: 音乐会数据集合（由后端脚本自动映射生成）
- `changelog.html`: 版本更新历史页面

## 网站收录进度
目前只收录了上海的音乐会，两周更新一次，后续技术升级或邀请感兴趣的朋友一起收集，扩展更多的城市
